# MANIFEST — DN-WTA v3 数据集（固定划分协议）

> 生成日期：2026-08-28 ｜ 生成器：`experiments/gen_dn_data.py`（md5 `3fe8c817a203cce2000674561638b87e`）
> 文件格式：DN-WTA v1（8 字段 Header + 三块，1+n+2mn 行）；动力学/信息边界与 v2 完全一致，见 `DN-WTA_v3_数据集说明.md`。
> 注意：v3 的 s01/s02 为**新生成实例**，与遗留 v2 的 `data/dn_3x50_K10_s1/s2.txt`（不同目录、不同参数）无继承关系，仅编号巧合。

## 1. 固定划分（禁止混用）

| split | 实例 | 用途 |
|---|---|---|
| **test** | s01–s02（2 个） | **正式对比 seed**：未来所有算法对比实验统一只用这 2 个实例（× 30 MC seeds） |
| train | s03–s26（24 个） | MARL 训练 |
| val | s27–s30（4 个） | 调参 / 早停 |

任何算法的超参**不得**依据 test 表现调整。基线（none/greedy/cplex，实例无关、零训练）直接在 test 上评估；MARL 在 train 训练、val 调参、test（2 实例 × 30 seeds）终评，另报告 train 均值–test 均值之差（泛化代价，指标⑩）。

## 2. 生成命令与参数

```bash
python experiments/gen_dn_data.py --seeds 1,2,...,30 --outdir data/dn-data-v3 --pad 2
```

| 参数 | 值 |
|---|---|
| m / n / K | 3 / 50 / 10（每波恰 5 个到达） |
| dt / delta_d / v_m / pcap | 10 s / 3.0 km/步 / 1.0 km/s / 95 |
| **mu**（v3 修订） | **6 / 平台（全局共享池 18 发）** |
| **w-trend**（v3 修订） | **1.5**：`w = max(1, round(U{1..99} × (1 + 1.5·k_arr/(K−1))))`，取值 [1, 248] |
| **quota**（v3 修订） | **1,1,3**（每波 1/2/3 步交战窗 = 1/1/3 个） |
| r0-min / r0-max / b-max / eps-max | 3 / 9 / 3 / 2（与 v2 一致） |
| seed 流 | 每实例 5 条独立 `RandomState(seed*100+1..5)`（split/r0/b/eps/w-p，与 v2 一致） |
| 实例 seed | = 文件号（s01→1 … s30→30） |

回归校验：`--w-trend 0 --mu 8 --quota 2,2,1` 生成 seed 1 与 v2 `data/dn_3x50_K10_s1.txt` **逐字节一致**（md5 `e27de92379a180fc7f545401e467c066`）。

## 4. 评估协议

- **所有算法的正式对比只在 test 的 2 个实例（s01/s02）上进行**（计算成本考量：cplex 逐步求解 × 多 seeds 开销随实例数线性增长，2 实例即可支撑 mean±std 与同 seed 配对检验）；
- 蒙特卡洛种子数：**30**（`--seeds 30`，v3 结局指标方差高于 v2）；
- 基线：`none` / `greedy`（+逐步参考解）/ `cplex`，实例无关、零训练，直接在 test 上评（实验 bank e11/e12/e13，见 `output/README.md`）；
- MARL：train（24 实例）训练、val（4 实例）调参、test（2 实例 × 30 seeds）终评；报告 train 均值–test 均值之差（泛化代价，指标⑩）；
- 批量评估入口：`experiments/dn_family_eval.py`（读本 MANIFEST 的 split 列表，逐实例复用 DN 管线并汇总）。
